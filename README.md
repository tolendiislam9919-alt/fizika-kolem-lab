# Денелердің көлемін өлшеу — 7-сынып

Интерактивті слайд-зертхана (физика, 7-сынып, «Тығыздық» бөлімі, 18-сабақ, §11).
Оқушы QR арқылы кіріп, атын жазады (аты экранда шығады), мұғалім «Бастау» басқан соң әркім өз телефонында тапсырма орындайды; соңында Kahoot тәрізді көлік жарысы бар.
Мұғалім: Төленді И.Н., «Тайтөбе ауылының жалпы орта білім беретін мектебі» КММ.

## Ашу
- Wi-Fi бар сыныпта: `start.bat` (телефондар компьютермен бір желіде болсын).
- Интернет арқылы: барлық файлды GitHub Pages-ке жүктеп, сілтемені ашу.
- `index.html`-ді екі рет басып ашсаңыз, слайд жұмыс істейді, бірақ QR шықпайды.
Толығырақ: `NUSQAULYQ.txt`.

## Басқару
- ← → немесе PageUp / PageDown — беттер
- F — толық экран, T — тақтаны жасыру/шығару
- `#N` — N-бетке тікелей өту

## Файлдар
- `index.html` — слайд; `phone_panel.js` — QR, тізім, жарыс
- `oqushy.html` — оқушының телефондағы беті; `kl_packs.js` — тапсырмалар мен жарыс сұрақтары
- `net.js`, `mqtt.min.js`, `qrcode.min.js`, `three.min.js`; `server.py`, `start.bat`
- `index_qr_jok.html` — QR-сыз алдыңғы нұсқа
